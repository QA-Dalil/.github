## How I approach testing

- **Understand the requirement:** review user stories, expected behavior, and edge cases before writing tests.
- **Design useful coverage:** create positive, negative, boundary-value, exploratory, and end-to-end scenarios.
- **Execute and record:** keep test steps, expected results, actual results, and execution status clear enough for someone else to repeat.
- **Report what matters:** write reproducible bug reports with impact, priority, severity, and supporting evidence.
- **Check the data:** use SQL to validate values shown in the application against PostgreSQL records.
- **Keep work traceable:** connect requirements, tests, results, and defects in Jira and Zephyr Essential.

Database QA work for an online learning platform. Includes a reproducible schema and sample data, analytical SQL queries, constraint checks, test cases, and execution documentation.
